# IslandDAO Website

The official IslandDAO website.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Project Structure

```
src/
├── app/           # Pages and routes
├── components/    # React components
└── lib/           # Utilities
```
